# Map variable names to their canonical names

Map variable names to their canonical names

## Usage

``` r
canonical_variable(x, rules)
```

## Arguments

- x:

  Character vector of variable names as reported.

- rules:

  Rules from
  [`read_rules()`](https://andjar.github.io/metawoRld/reference/read_rules.md).

## Value

Character vector of canonical names (`NA` where unknown).
