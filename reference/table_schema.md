# Frictionless Table Schema for the data points of a form

Frictionless Table Schema for the data points of a form

## Usage

``` r
table_schema(form)
```

## Arguments

- form:

  A form from
  [`get_schema()`](https://andjar.github.io/metawoRld/reference/get_schema.md)
  (with `data_points`).

## Value

A list that serializes to a Table Schema.
